이슈 :

    - 두 번째 문제로, 현재 스크린에는 안드로이드 권한을 4개 요청하도록 설정되어 있지만, 스크린에는 2개만 나타나고 있습니다. 추가적인 두 개의 권한이 필요한지 여부를 고려해야 합니다. 새로운 권한을 추가할 경우, iOS와의 디자인 일관성이 깨지게 됩니다.
